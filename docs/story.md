# Сюжет: захват города (черновик Руслана, 2026-10-22)

Идея: игра идёт по ночам-миссиям. Каждые 5 ночей команда захватывает новый район города и открывает его ключевые локации. Начало района — установка шатра (опорная точка), конец — зачистка района и босс.

Зомби не появляются случайно по всей карте: они идут **бесконечным потоком с разных сторон** из точек в **100–150 студах** от опорной точки миссии (шатра, конвоя, цели) и пока миссия не выполнена.

## Что уже есть в игре и подходит

- Цикл день/ночь, голосование за конец дня, сгорание зомби на солнце (финальный босс — исключение).
- Боссы 5/10/15 (Качок, Гаргантюа, Повелитель тёмных), перки после босса.
- Оборудование (проволока, турель) — основа для «установки шатра».
- Машины (в т.ч. с пулемётом) — основа для конвоя.
- Военная база, бункер (`Workspace.Bunker`), 6 шатров, кафе, автоматы.

## Что нужно сделать (по порядку)

1. **Система миссий ночи** (`MissionService` + таблица `Config.Missions` по ночам): тип, цель, условие победы/провала, точка миссии. RoundService вместо «убей всех» ждёт выполнения миссии.
2. **Поток зомби вокруг точки миссии** вместо спавна по всей карте (100–150 студов, с разных сторон, пока миссия идёт). Сейчас: `ZombieService.pickSpawnPosition` по маркерам `ZombieSpawn*`; нужен режим «кольцо вокруг якоря».
3. **Миссии по типам:** scout (дойти до точек), clear (убить N / зачистить зону), build (поставить шатёр), escort (конвой), defend (шатёр с HP), multi-defend (несколько).
4. **Районы:** список районов и их локаций, открытие после ночей 5/10/15.
5. **Новые виды зомби** на волны (см. вопросы).
6. **Метро** — отдельная локация (сэмпл готов: `Workspace.Metro`).
7. **Финальный босс** без урона от солнца и боевая арена у военной базы.

## Вопросы по сюжету

- Как делим город на районы: по готовым шатрам (6 штук по карте) или по границам, которые нарисуете вы? Где «основная база» и откуда стартует 1-й район?
- Ночи без «убей всех» (разведка, конвой): время ночи — по миссии, или всё равно ограничено таймером?
- Дневная миссия на 16-й ночи: день остаётся днём с зомби? (сейчас днём зомби сгорают)
- Прогрессия числа зомби (потолок 250/500 к 20-й) остаётся, или поток «бесконечный» ограничивается только живыми на карте (40 на игрока)?
- Новые виды зомби: пришлёте идеи или предложить по районам (метро — слепые/ползуны, военная база — стрелки, аномалии — призраки…)?

## Метро: сэмпл-локация (2026-10-22)

`Workspace.Metro` — изолированная «коробка» в небе над городом (начало координат по Y = 600, игроки туда попадают только по телепорту или будущей лестнице). Станция метро для ночи 18 (зачистка); дальше дизайном занимается Руслан, структура разложена по папкам:

- `Shell` — стены, потолок, билетный зал (этажом выше), служебная комната;
- `Platform` — две платформы (по 14 студов), путевое русло с двумя колеями, пандусы-переходы на концах станции;
- `Tunnels` — западный и восточный тоннели по 120 студов с обвалом в конце;
- `Props` — скамейки, колонны-ориентиры, застывший поезд (укрытия), турникеты, касса, ящики, лестница выхода и люк (заглушка);
- `Lights` — потолочные лампы (часть погашена) и красная аварийка у тоннелей;
- `Markers` — `Metro_Spawn` (появление команды), `Metro_Exit` (выход на поверхность), `Metro_Boss`, `Metro_Vending`, `Metro_ZombieSpawn_1…8` (тоннели и платформы), `Metro_Objective_1…3` (гнёзда/цели зачистки).

Все маркеры достижимы по `PathfindingService` от `Metro_Spawn`. Размер станции: 160 × 48, потолок 12 студов, тоннели 14 × 9. Телепорт для осмотра в Studio (Command bar): `workspace.Metro.Markers.Metro_Spawn.Position` — это и есть точка входа (50, 600.6, 14).
Объекты лежат в файле места (не в репозитории): сохраните место. Код метро (переход, спавн зомби по `Metro_ZombieSpawn_*`, цели) — отдельная задача после согласования миссий.
